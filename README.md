# Lestari Alam Club · SK Bukit Damansara

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Hi! I'm Hadeef, an ex student from skbd that wants to improve school sustainability by making a website for the Lestari Alam Club. My journey was to help students, teachers, and club committee members track recycling contributions, club activities, Green Points, badges, and member records in one place.

The goal is to make school sustainability easier, more organized, and more fun for students. Its open-source for everyone and its completely free. Welp, thats from me (hadeef). bye!!!

Founder, Hadeef

## Features

- Club member sign up and login
- Supabase authentication
- Club member portal
- Recycling contribution records
- Green Points and level system
- Club badges
- Class leaderboard
- Activity registration
- Password reset page
- Responsive school club website design

## Tech Stack

- HTML
- CSS
- JavaScript
- Supabase Auth
- Supabase Database

## Notes

This website is for the Lestari Alam Club at SK Bukit Damansara. It stores club member records through Supabase and is intended to support school environmental activities.

Good luck, and thank you for supporting green habits in school 🌿
